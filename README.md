## Tomethy's Stellar Reserve (new)

Static Astro website for **Tomethy's Stellar Reserve** — a Star Citizen fueling contractor and ship financing bank operated by Tomethy.

### Run locally

```bash
npm install
cp .env.example .env
npm run dev
```

### Deploy

- Build: `npm run build`
- Output: `dist/`
- Hosting: Netlify or Vercel
